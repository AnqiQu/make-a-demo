# Prepare Repos in Ephemeral Workspaces

MakeADemo will replace the preparation-first user flow with a pipeline that accepts a repo link and supporting documentation, runs a fast static Repo Security Screen, then lets an agent work inside a locked-down ephemeral cloud workspace to discover existing demos, prepare a deterministic demo runtime, and gather context for later script and capture stages. We chose this over requiring the maker to prepare the repo up front because it makes the product flow faster and more automated, while still avoiding write access to the maker's source repo; if preparation cannot produce a plausible deterministic runtime, MakeADemo returns a targeted Preparation Fallback Prompt instead of generating a script from an unusable app.

Repo Preparation, Script Generation, and repair prompts may run in one long-lived OpenCode session, but the stage contracts remain separate. Capture Path Validation is the non-agent gate before Footage Capture trusts the prepared app and generated Video Script Package.
